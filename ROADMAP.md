# Roadmap Android

## Fase 1 — Fundação (estrutura iniciada)
- [x] Projeto Compose, navegação inicial, modo claro/escuro.
- [x] Clientes mínimos com IDs e dados criptografados.
- [ ] Validar compilação no Android Studio + testes reais.
- [ ] Banco estruturado com migração de esquema e backup criptografado versionado.
- [ ] Autenticação local opcional (PIN/biometria), recuperação e modelo de ameaça.

## Fase 2 — Avaliações
- [ ] Formulários de anamnese por nível (iniciante/intermediário/avançado).
- [ ] Avaliações físicas, medidas, protocolos e vínculo com cliente.
- [ ] Validação dos cálculos, edição, histórico e migração de dados com consentimento.

## Fase 3 — Evolução e relatórios
- [ ] Gráficos e comparativos por período.
- [ ] Exportação PDF nativa, sem elementos da interface no relatório.
- [ ] Compartilhamento Android via SAF/FileProvider.

## Fase 4 — Cobranças e dados
- [ ] Cobranças, pagamentos pendentes e botão Receber.
- [ ] Salvar em armazenamento escolhido pelo usuário via SAF, sem permissões invasivas.
- [ ] Backup, restauração e integridade; operações atômicas e criptografia ponta a ponta do arquivo.

## Fase 5 — QA e produção
- [ ] Testes instrumentados, segurança, acessibilidade, performance e responsividade.
- [ ] CI, assinatura de APK/AAB e documentação de publicação.
