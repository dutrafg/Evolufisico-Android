## Critérios para homologar 100/100 em cada Alpha

1. Cada etapa precisa de evidência técnica ou validação manual reproduzível.
2. Testes de compilação, JUnit, Lint e emulador não substituem QA visual em smartphone.
3. Importação e restauração devem ser testadas com dados fictícios e cópia de backup preservada.
4. Nenhum APK debug atualiza o app principal se a assinatura for diferente.
5. A segurança/criptografia para dados novos está temporariamente desabilitada por decisão de prototipagem: não utilizar dados pessoais sensíveis.
